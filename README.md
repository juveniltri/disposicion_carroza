# Carroza — Formación

App de un solo archivo (`index.html`, sin build ni dependencias) para configurar y exportar en imagen la formación de la carroza.

## Desplegar en GitHub Pages

1. Crea un repo nuevo (o usa uno existente) y sube `index.html` a la raíz (o a una carpeta `/docs`).
2. En el repo: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/ (root)` (o `/docs` si lo has subido ahí) → **Save**.
4. En 1-2 minutos la web estará en `https://<tu-usuario>.github.io/<nombre-repo>/`.

## Uso

- Cada grupo (Dioses, Diosas con antorcha, Guerreras, Guerreros) tiene un **Total** y unas **Columnas**; las filas se calculan solas.
- Activa **Modo avanzado** en un grupo si prefieres fijar tú las filas y columnas exactas (el total se calcula solo).
- Diosas y Guerreros son grupos "por lado": el número que pones se coloca a la izquierda y a la derecha por igual.
- **Exportar imagen** descarga un PNG con el diagrama y el glosario debajo, listo para compartir.
